# Network-Extended Theory of Planned Behavior for Digital Collaboration in Construction Project Management

This repository provides reproducibility code and supplemental analyses for the study:

**Network-Extended Theory of Planned Behavior for Digital Collaboration in Construction Project Management**

## Repository Sections

To clearly distinguish study data from supplemental analysis materials, please use the following sections:

- **[Data Availability](./DATA_AVAILABILITY.md)** — describes availability and conditions of use for the respondent-level study data.
- **[Supplemental Material](./SUPPLEMENTAL_MATERIAL.md)** — provides the current Jupyter Notebook, archived original notebook, software requirements, and supplementary robustness and sensitivity analyses.

## Current Analysis Notebook

The current notebook for the revised manuscript is:

**[`network_extended_tpb_v02.ipynb`](./network_extended_tpb_v02.ipynb)**

It contains:

- **Part A — Primary Manuscript Analyses:** reproduces Tables 1–6, Figures 1–2, and the main hypothesis tests reported in the revised manuscript.
- **Part B — Supplementary Robustness and Sensitivity Analyses:** provides additional measurement, shared-variance, role-sensitivity, common-method, and mediation-sensitivity analyses.

**Open v02 directly in Google Colab:**  
https://colab.research.google.com/github/praiseCM/digital-collab/blob/main/network_extended_tpb_v02.ipynb

The earlier notebook, `network_extended_tpb_v01.ipynb`, is retained as an archive of the original-submission analysis.

## How to Run

### Google Colab

Open `network_extended_tpb_v02.ipynb` using the Colab link above and select **Runtime > Run all**.

### Local Jupyter

1. Download or clone this repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Open:

```text
network_extended_tpb_v02.ipynb
```

4. Run the notebook from top to bottom.
